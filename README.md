# Portafolio CEMR

Sitio personal de Coromoto Malavé (CEMR): QA Engineer y desarrolladora frontend. El contenido está en español y en inglés.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Rutas

- `/` inicio
- `/contact` contacto
- `/portfolio` trabajos
- `/portfolio/:slug` ficha de un proyecto
